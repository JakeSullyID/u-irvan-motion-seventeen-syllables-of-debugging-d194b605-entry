# Seventeen Syllables of Debugging

This entry is a TypeScript program created for the make.fun bounty "Seventeen Syllables of Debugging", which outputs a concise three-line haiku capturing the isolated, freezing reality of late-night debugging sessions.

## Haiku

```text
Null ref in the dark,
Breakpoint halts the crashing loop,
Coffee turns to ice.
```

## How to Run

Execute the program with Node.js to generate the output file:
```bash
node main.ts
```
This writes the haiku to `/output/entry.txt`.
